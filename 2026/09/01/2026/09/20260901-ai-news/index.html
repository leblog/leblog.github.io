今日重点关注

1. 英伟达向联发科投资 35 亿美元，覆盖 AI、PC 芯片、汽车三大领域

来源：IT之家

英伟达与联发科宣布加深长期合作，英伟达向联发科投资 35 亿美元，双方将在 AI 基础设施、本地 AI 计算（AIPC）和汽车三大领域打造下一代 AI 计算平台；联发科将采用 NVIDIA NVLink Fusion，为超大规模企业、云服务商和前沿模型开发者提供预验证的异构集成路径。算力版图从「抢 GPU」进一步走向「绑定芯片设计」。

2. 智能体请求暴增 9.4 倍、token 账单却没涨：Uber 公开 AI 软件工厂省钱方法

来源：InfoQ

Uber 公开其「AI 软件工厂」的成本治理经验：在智能体请求量暴涨近 9.4 倍的同时，通过缓存、请求合并、模型路由与工程化治理，把 token 账单控制在几乎没有增长。对正被 Agent 成本压得喘不过气的团队，这是一份难得的「省钱实操」。

3. 从出片到出海：AI MediaKit 重塑短剧全链路生产力

来源：InfoQ

短剧出海竞争白热化，AI MediaKit 把「出片—本地化—出海分发」的链路重做了一遍：从脚本、分镜、翻译到多语配音与素材管理，用 AI 把原本分散在多个工种的生产力收拢成统一工作流，显著压缩制作与出海周期。

4. AI 写代码飞快，为何交付没有变快？小红书 Muse 的 Agentic 架构实践

来源：InfoQ

小红书 Muse 团队直面一个普遍困境：AI 生成代码很快，但端到端交付并没同步提速。文章拆解其 Agentic 架构——如何把代码生成嵌进需求、评审、测试、发布的真实研发闭环，而不是停留在「补全片段」层面，给出「提效 ≠ 提速」的架构答案。

5. 智能体适应度函数：将演进式架构扩展至确定性规则之外

来源：InfoQ

把「演进式架构」从确定性规则推进到智能体世界：用「适应度函数」衡量系统在不同演化路径上的健康度，让架构决策能在 Agent 持续迭代、环境动态变化下保持可控，是 Agent 时代架构治理的新思路。

6. AI Coding 之后，如何让 Agent 进入企业研发全链路？得物推荐的 Harness 实践

来源：InfoQ

得物分享其 Harness 实践：在 AI Coding 已经跑通的基础上，进一步用 Agent 串联企业研发全链路——从需求拆解、任务编排到质量门禁与上线，探索「编码只是 Agent 的一环」的组织级落地范式。

7. OpenClaw 从意外爆红到「无人问津」：一个开源 AI Agent 的八个月过山车

来源：InfoQ

OpenClaw 用八个月走完「爆红—沉寂」的完整曲线：文章复盘这个开源 AI Agent 项目从意外走红到热度退潮的全过程，对「开源 Agent 如何穿越炒作周期、维持真实用户」是难得的样本研究。（相关：少数派派早报提到 OpenClaw 推出 2.0 版本更新。）

8. 「你以为买的是 DeepSeek Flash，到手可能是 1.5 bit 缩水版」：Pi 核心贡献者谈 AI Token 黑箱

来源：InfoQ

Pi 核心贡献者揭开源 Token 的「缩水黑箱」：同样标称的模型，底层量化与精度差异可能让实际拿到的能力大幅缩水。文章提醒开发者在比价与选型时，要穿透「Token 价格」表象看真实推理质量，避免被低价误导。

9. 派早报：OpenClaw 推出 2.0 版本更新，网易 CC 直播正式停运等

来源：少数派

少数派早报聚焦 OpenClaw 2.0 版本更新、网易 CC 直播正式停运等科技动态；其中 DotSkill 等 AI 能力可让助手通过自然语言直接操控墨水屏摘录，是端侧 AI 交互的小而美的进展。
